CS-330 Computational Graphics and Visualization

Project Overview

For my CS-330 final project, I created a 3D scene using C++ and OpenGL. Throughout the course, I learned how to build 3D objects using different shapes, apply textures and lighting, and set up camera controls to move around the scene. This project helped me understand how different parts of a graphics program work together to create a complete 3D environment.

How Do I Approach Designing Software?

When designing software, I like to start by understanding what the final result should look like and then break the project down into smaller parts. For my 3D scene, I had to figure out which basic shapes could represent the objects I wanted to create and how to position them correctly.

One skill I improved was planning how different objects would fit together in a 3D environment. I also learned that it is easier to make adjustments when the code is organized and each part of the scene has a purpose. In future projects, I can use this same approach by planning first, breaking down complicated tasks, and making improvements as I go.

How Do I Approach Developing Programs?

My approach to programming involves working on one feature at a time and testing it before moving forward. During this project, I worked with transformations, camera movement, textures, and lighting. Each milestone helped me build on what I learned in the previous modules.

Iteration was a big part of my development process because everything did not work correctly the first time. I had to troubleshoot issues with textures, file paths, and how objects appeared in the scene. Instead of changing everything at once, I learned to focus on individual problems and test different solutions.
By the end of the course, I became more comfortable reading existing C++ code, understanding how different functions work together, and making changes without affecting the entire program.

How Can Computer Science Help Me Reach My Goals?

Computer science is helping me develop the technical and problem-solving skills I need for my future career. Even though I am interested in cybersecurity, learning computational graphics has helped me understand programming from another perspective.
Working with OpenGL gave me more experience with C++, debugging, and understanding how software communicates with hardware. These skills can be useful in other computer science courses because they require logical thinking, attention to detail, and the ability to troubleshoot problems.

Professionally, this project demonstrates that I can work through a development process, learn unfamiliar technologies, and build a functioning application. I can apply these skills to future software development, cybersecurity, and other technical roles.
